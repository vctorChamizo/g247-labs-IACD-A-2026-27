Primera nota aprobada

Qué observar

  1. querySelector selecciona elementos HTML con selectores CSS.
  2. addEventListener registra la función que responde a cada click.
  3. textContent actualiza el texto de un elemento sin crear HTML nuevo.
  4. La lógica de variables, condiciones, while y funciones no cambia.
