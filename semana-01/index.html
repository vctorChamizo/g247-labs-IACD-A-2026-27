HTML semántico

Esta página utiliza elementos HTML para expresar la estructura y el significado del contenido antes de aplicar ningún estilo visual.

Consultar HTML en MDN

Conceptos principales

Encabezados y párrafos

Los encabezados organizan la información y los párrafos desarrollan cada idea.

Listas

Las listas agrupan elementos relacionados cuando el orden no forma parte del significado.

Enlaces

Los enlaces permiten navegar hacia otros recursos o a secciones del mismo documento.

Contenido estructurado

  1. El navegador recibe un documento HTML.
  2. Los elementos describen la función de cada bloque.
  3. CSS podrá modificar después su presentación visual.

Qué observar

  • La diferencia entre header, main, section, article, aside y footer.
  • La jerarquía de encabezados desde h1 hasta h3.
  • La ausencia de atributos class y de hojas de estilo.
