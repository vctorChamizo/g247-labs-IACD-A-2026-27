# Ejemplos de clase — G247

Ejemplos progresivos empleados en las clases de Programación de Aplicaciones Web.

| Semana | Contenido | Carpeta |
|---|---|---|
| 1 | HTML semántico sin estilos | [`semana-01/`](semana-01/) |
| 2 | El mismo documento con CSS básico | [`semana-02/`](semana-02/) |
| 3 | JavaScript: variables, tipos, control de flujo y funciones | [`semana-03/`](semana-03/) |
| 4 | El mismo ejemplo conectado al DOM mediante eventos | [`semana-04/`](semana-04/) |

La semana 3 separa la lógica de JavaScript de la interfaz: sus resultados se observan en la consola del navegador, sin usar todavía el DOM. La semana 4 reutiliza el objeto, las condiciones y las funciones de esa semana para actualizar la página mediante eventos.
