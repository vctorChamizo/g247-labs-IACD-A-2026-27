JavaScript: fundamentos

Este documento solo carga el fichero script.js. Los resultados se consultan en la consola de herramientas para desarrolladores del navegador.

Ejemplos incluidos

  1. Variables, reasignación y tipos de datos.
  2. Valores primitivos, referencias y objetos.
  3. Condicionales y bucles for/while con números pares e impares.
  4. Funciones para obtener el máximo de un array y comprobar un palíndromo.

No se selecciona ni se modifica ningún elemento HTML: el DOM se introducirá en la semana 4.
